Make Life Slower — Alpine Farm
Upload this ZIP as an HTML5 game to itch.io, or host all files on GitHub Pages. index.html must be at the root. Single-threaded WebGL 2 build; no special cross-origin headers required.
Controls: WASD walk, mouse look, Shift run, V FPS/TPS, 1–4 tools, E interact, I inventory, M map, Esc pause/settings.
Serve over HTTP(S); do not open index.html directly as a local file. Saves are per website/browser.
